### 💹 FinSentAI — Financial Intelligence Platform

**FinSentAI** is an end-to-end financial sentiment analysis and market intelligence platform combining NLP, machine learning, financial news, market data, analytics, and actionable signal generation.

**Highlights:**

* TF-IDF + SVM sentiment classification
* VADER sentiment analysis with financial-domain lexicon
* Ensemble sentiment prediction
* Financial news ingestion
* Market data integration
* BUY / SELL / HOLD / WATCH / CAUTION signal engine
* REST API with API-key authentication
* User authentication and role-based features
* Watchlists and alerts
* Analytics dashboards
* AI assistant
* Financial report builder
* Stock comparison, ticker and heatmap workflows
* Docker + Gunicorn deployment setup
* Pytest test suite
* GitHub Actions CI workflow

**Stack:** Python · Flask · scikit-learn · NLP · VADER · JavaScript · REST API · Docker · Pytest
